OEIS A000445 · Erdős problem #436

Consecutive Residues

Pick a prime p and call n an 8th-power residue if n ≡ x⁸ (mod p) for some x. Sooner or later two consecutive numbers r and r + 1 are both residues. How long can that first pair be put off? Lehmer, Lehmer, Mills and others answered this for squares through 7th powers between 1962 and 1964. For 8th powers the answer is a(8) = 1,508,324. It is reached by infinitely many primes, and no prime does better.

The whole game is choosing values on primes

For a prime p = km + 1, fix a primitive root g. Every n has an index: gind n ≡ n (mod p). Then n is a k-th power residue exactly when ind n ≡ 0 (mod k). Write χ(n) = ind n mod k. Indices add when numbers multiply, so χ is fixed by its values on the primes. Any choice of values on finitely many primes is realized by infinitely many p; for k = 8, χ(2) must be even, because 2 is a square mod every p = 8m + 1. So a(k) is a puzzle: give each prime a value mod k so that the first r with χ(r) = χ(r + 1) = 0 comes as late as possible.

Each strip shows one maximal choice, the primes on a log scale up to the last one that needed a value. Most primes get χ = 1 (left blank); the colored ticks are the exceptions. Primes beyond the strip are given a value that makes all their multiples non-residues, which is possible because a large prime q only appears as j·q with j < q.

Ordinary primes never get close

The extremal values come from primes that agree with the special character on every prime up to about 1.5 million, so they are astronomically large. A typical prime finds its first pair quickly. Why 1,508,325 is impossible

To show that no character avoids a pair below 1,508,325, a program tries values for the primes in order (2, 3, 5, …). Each time a choice would create a residue pair, it cuts that branch. A branch also dies when a later prime has no safe value left. The whole search tree has 78,438 nodes, and every dead end is witnessed by one explicit pair (r, r + 1). An independent checker re-derives all of them by factoring.

    Method

    How a(8) was settled

    The search is the 1964 Brillhart–Lehmer–Lehmer "case vector" method, with forward checking added. When a number's only undecided prime is its largest, values for that prime that would pair it with a known residue neighbor are crossed off in advance. The search also treats characters that differ by a unit multiple mod 8 as the same, and it stops at primes above √N, which can always be made harmless. Each yes/no run takes about 30 seconds. The same program reproduces a(2) through a(7).

    Don Reble had shown 1,499,876 ≤ a(8) ≤ 1,508,324 in 2019. The new computation finds a character whose first pair is exactly 1,508,324, so his upper bound is the value. It also writes a proof tree showing that nothing reaches 1,508,325. Both were checked by separate Python code. The code, the certificate and the logs are in oeis-results/A000445.
